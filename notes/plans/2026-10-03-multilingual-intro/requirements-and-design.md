# 需求与设计规格

关联：[开发计划](README.md)。状态：V2 按用户要求改为每次刷新播放；视觉参数沿用 V1，真机验证仍待完成。

## 1. 产品需求

访问者首次直接进入首页，以及每次刷新首页时看到短暂的多语言问候，随后黑色幕布带圆弧边缘向上退场，露出 Aeneas 原有首页。开场的记忆点来自语言节奏与揭幕；结束后应立即恢复阅读和导航。

用户要求达到参考效果，本草案保留参考的语言顺序、时序、黑白开屏和曲线方式，不在第一版自行压缩成两秒或替换成普通淡出。首页原有浅色背景在揭幕后露出。

| 纳入本轮 | 本轮不覆盖 |
|---|---|
| 首页多语言开屏与弧边揭幕 | 全站内容、信息架构与 Hero 排版重做 |
| 桌面和手机尺寸适配 | 参考站的地球、粒子、文字扫描和其他图形效果 |
| 首次访问、刷新、锚点、减少动画规则 | 全站页面名称转场与预取 |
| 滚动、焦点、取消及失败后恢复 | 游戏源码、游戏页面、简历仓库和部署流程重构 |

如果用户选择整站改版，上表需重写并另行审查，不能将这些排除项作为固定产品限制。

## 2. 可复现的视觉规格

参数依据 [PageTransition.astro](https://github.com/7-an/ansyn-lab/blob/4e2e0ab82911dc3542e2a6a77c16557655d30c0d/src/components/PageTransition.astro#L15) 和 [reveal()](https://github.com/7-an/ansyn-lab/blob/4e2e0ab82911dc3542e2a6a77c16557655d30c0d/src/lib/page-transition.ts#L117)。这些是参考事实；在个人网站中独立实现。

| 项目 | 首版目标 |
|---|---|
| 语言 | Hello → Bonjour → Ciao → Olá → こんにちは → Hallå → Guten Tag → 你好 |
| 背景 / 文字 | #0f0f0f / #fdfdfd |
| 小圆点 | 文字左侧的实心圆点，随字号缩放 |
| 字体 / 字号 | Helvetica Neue、Arial、sans-serif；clamp(36px, 5vw, 68px) |
| 位置 | 整组水平居中；桌面比视口中心高 50px，≤540px 时高 30px |
| 字体等待 | 最多 300ms，不等待全站图片加载 |
| Hello | 延迟 250ms，700ms 淡入并从下方 20px 回到原位 |
| 中间六种语言 | 各 150ms，直接替换同一个文字节点，不加逐词淡入淡出 |
| 最终“你好” | 停留 400ms |
| 文字入场缓动 | cubic-bezier(.16,1,.3,1) |
| 文字退场 | 450ms，线性淡出 |
| 主幕布退场 | 800ms，translateY(0) → translateY(-110%) |
| 退场缓动 | cubic-bezier(.76,0,.24,1) |
| 弧边 | CSS 大椭圆裁切；桌面初始 10vh，≤540px 时 5vh |
| 弧边收缩 | 延迟 150ms，850ms 高度收至 0；主幕布完成时统一清理 |

主动画顺序步骤按源码计算约 3.05–3.35 秒，不包含脚本下载或主线程阻塞。弧边收缩与主幕布并行；主幕布结束后取消剩余动画，不能把所有动画时长简单相加。

视觉比较使用相同视口大小。验收关注结构、节奏、圆弧和露出方式；不同设备字体回退和底层首页内容不同，不承诺逐像素一致。调整参数须记录原因，不能为“更顺滑”暗中改成另一种效果。

## 3. 行为规格

| 情况 | 目标行为 |
|---|---|
| 新标签页首次直接进入首页，无 hash，允许动画 | 播放一次 |
| 同一标签页刷新，包括带 hash 的首页 | 每次播放，不受已访问会话记录影响；保留原有锚点与滚动位置 |
| 同一标签页返回首页 | 跳过，不影响浏览器前进后退 |
| 带 #lab、#about 等锚点直接进入 | 跳过，进入目标内容 |
| Lab/Garden/详情/游戏页面 | 不引入开屏资源、不播放 |
| 系统减少动画或 ?motion=reduce | 直接显示内容 |
| 播放中切换为减少动画 | 立即结束并清理，不重播 |
| sessionStorage 不可用 | 跳过，不阻断页面 |
| JavaScript 禁用 | 静态首页正常可读 |
| 不支持所用动画能力 | 跳过，保证内容可用 |
| 用户按 Escape | 立即结束开屏并恢复交互 |
| 开屏中使用键盘 | 焦点不进入被遮住的主页；结束后不残留模态焦点锁 |
| 动画中失去页面可见性 | 结束可选开屏，回到页面时不重播、不残留滚动锁 |
| 独立动画脚本加载失败 | head 的独立释放逻辑撤销开屏状态 |
| 超时释放后脚本迟到、异步等待结束 | 不重新播放、不重新锁滚动 |

首次播放规则原参照 [BaseLayout.astro](https://github.com/7-an/ansyn-lab/blob/4e2e0ab82911dc3542e2a6a77c16557655d30c0d/src/layouts/BaseLayout.astro#L112)，V2 按用户指令将刷新优先级置于会话记忆和 hash 之上。网站使用自己的会话键名，进入首页时记录已访问，用于普通返回时跳过；刷新会重播。减少动画与能力/存储不可用仍直接放行。

参考没有可见的“跳过”按钮。首版保留 Escape 取消；是否增加触屏“跳过”入口作为产品选择单独记录，不以默认添加按钮影响目标外观。

不朗读连续高速切换的八种问候；为模态层提供稳定的可访问名称，动态文字作为视觉内容。结束后恢复进入前合理的焦点；不强制滚动到顶部、不自动替访客选择导航目标。

## 4. 成功标准

1. 正常首次进入按规定顺序和节奏播放，最后停在“你好”，出现清晰弧边揭幕。
2. 没有主页先闪现后被覆盖、文字换词导致整组中心偏移、水平溢出或动画结束后空白。圆点随词宽变化而移动，符合参考整组重新居中的方式。
3. 幕布结束或取消后，原首页内容、导航、锚点、滚动与键盘交互正常。
4. 刷新、锚点、减少动画、脚本失效、存储不可用等路径不留下黑屏或滚动锁。
5. 没有新增第三方运行时依赖，其他页面不受到开屏样式或逻辑影响。
6. 用户查看桌面和手机效果后确认是否达到参考观感；未做真机验证时明确保留该项。

参考仓库没有标明整站许可，第三方效果的许可证不能覆盖此开屏。采用独立实现，不整段搬入其 Astro/TypeScript 模块或个人内容。
