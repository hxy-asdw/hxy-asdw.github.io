# V2 每次刷新播放

日期：2026-10-03。用户新要求：每次刷新首页都弹出多语言开屏。基于已保存的 V1 修改；V2 本地快照形成时尚未提交、推送或部署，后续发布状态见[部署与云端交接](deployment-and-handoff.md)。

## 1. 变更范围

产品仅改 index.html 的 head 播放判定：识别 reload 后，不再因已访问会话记录或 hash 跳过。动画脚本、视觉样式、内容数据及其他页面未改。

| 场景 | V2 行为 |
|---|---|
| 普通首页刷新 | 每次播放 |
| 带 #lab 等锚点刷新 | 每次播放，hash 与原有浏览器滚动位置保留 |
| 锚点直接进入、普通返回和历史返回 | 沿用 V1 跳过规则 |
| 系统减少动画 / ?motion=reduce | 仍直接显示内容 |
| 存储或动画能力不可用、JS 禁用 | 沿用 V1 放行与恢复方式 |

## 2. 针对性检查

浏览器：Codex In-app Browser，通过 CUA 操作。预览：http://127.0.0.1:8765/。

| 检查 | 结果 |
|---|---|
| 已播放过的同一标签页连续刷新两次 | 两次都从 Hello 开始，到你好及正常退场；结束后模态关闭、活动属性移除、滚动恢复 |
| #lab 直接进入后刷新 | 直接进入跳过；刷新播放，保留 hash 和浏览器位置 |
| ?motion=reduce 刷新 | 仍不播放，无模态或滚动锁 |
| Lab 页面历史返回首页 | 不重播，无残留状态 |
| 代码审阅 | 仅刷新优先级改变，无滚动重置或动画参数变更 |
| 两段 inline 脚本语法、git diff --check | 通过 |
| 正式首页控制台错误/警告 | 空 |
| V1 原有文件保护与 V2 重建 | 快照哈希核对通过 |

V1 的桌面/手机视觉、异常释放和子页检查没有重复执行：这些实现未改。V1 记录保留为历史结果，当前刷新规则以本记录为准。系统减少动画变化、真实切标签与 iOS 真机的待验证项继续沿用。
